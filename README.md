# Nuno Tamada — Portfolio

Personal portfolio site for [Nuno Tamada](https://github.com/EvosROAR). Built with Next.js and deployed on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy to Vercel

1. Push this repo to GitHub
2. Import at [vercel.com](https://vercel.com)
3. Deploy — no environment variables needed

Suggested project name: `nuno-tamada` → URL `nuno-tamada.vercel.app`

## Edit content

Update `src/data/site.ts` to add projects, links, or skills.
